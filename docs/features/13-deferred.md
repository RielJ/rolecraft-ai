# Deferred ideas

Ideas the first plan deferred. None blocks the MVP. Give one its own feature doc when real use shows a need.

| Idea | What it would do | Pull into scope when |
|---|---|---|
| Near-match facts on re-import | When a re-imported CV changes a fact slightly, say "this replaces FACT-12" instead of adding a second fact. | Re-importing your CV leaves duplicate facts you have to clean by hand. |
| Output version history | Keep earlier versions of a resume, letter or answer after a redraft or edit. | A redraft loses text you wanted back. |
| "Not a duplicate" memory | Remember that two jobs the app called likely duplicates are different. | The same false duplicate keeps coming back after Refresh. |
| `status_events` table | Record each board status change with its time, for history and stats. | You want to know how long applications sat in each status. |
| Board drag and drop | Move a job between board columns by dragging. | Changing status from the menu slows you down. |
